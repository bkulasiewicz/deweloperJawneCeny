Automatyzacja jawnych cen mieszkań dla deweloperów nieruchomości - generowanie danych zgodnie z polską ustawą o jawności cen do portalu dane.gov.pl.

Automates transparent housing prices for real estate developers - generates data compliant with Polish price transparency law for dane.gov.pl portal.

== Description ==

**Deweloper Jawne Ceny** to wtyczka WordPress stworzona specjalnie dla polskich deweloperów nieruchomości, którzy muszą wypełniać obowiązki jawności cen mieszkań wynikające z Ustawy z dnia 21 maja 2025 r. o zmianie ustawy o ochronie praw nabywcy lokalu mieszkalnego. Wtyczka automatyzuje proces publikacji jawnych cen nieruchomości w formacie wymaganym przez portal dane.gov.pl.

= Główne funkcje =

* **Zarządzanie danymi dewelopera** - przechowywanie informacji o firmie deweloperskiej
* **Katalog inwestycji** - zarządzanie projektami mieszkaniowymi  
* **Cenniki mieszkań** - wprowadzanie i aktualizacja jawnych cen poszczególnych lokali
* **Automatyczne generowanie plików** - tworzenie plików XML i CSV z jawnymi cenami zgodnych z wymogami portalu dane.gov.pl
* **Historia publikacji** - śledzenie wszystkich publikacji danych
* **Publiczne linki** - automatyczne udostępnianie plików dla organów państwowych
* **Wyświetlanie na stronie** - podstawowe opcje prezentacji lokali dla klientów

= Zgodność z prawem =

Wtyczka zapewnia pełną zgodność z polskimi przepisami dotyczącymi jawności cen nieruchomości:

* Automatyczne generowanie plików w formacie XML zgodnym ze schematem dane.gov.pl
* Eksport danych w formacie CSV dla łatwej analizy
* Publiczne udostępnianie danych pod stałymi adresami URL
* Automatyczne tworzenie sum kontrolnych MD5

== Description (English) ==

**Deweloper Jawne Ceny** is a WordPress plugin created specifically for Polish real estate developers who must comply with obligations arising from the Act of May 21, 2025 on amending the act on the protection of the rights of residential premises buyers.

= Key Features =

* **Developer data management** - storing information about the development company
* **Investment catalog** - managing residential projects
* **Property pricing** - entering and updating prices of individual units
* **Automatic file generation** - creating XML and CSV files compliant with dane.gov.pl portal requirements
* **Publication history** - tracking all data publications
* **Public links** - automatic sharing of files for government authorities
* **Website display** - basic options for presenting properties to clients

= Legal Compliance =

The plugin ensures full compliance with Polish regulations regarding real estate price transparency:

* Automatic generation of XML files compliant with dane.gov.pl schema
* Data export in CSV format for easy analysis
* Public data sharing under permanent URLs
* Automatic MD5 checksum generation

**Premium version:**

== Installation ==

= Automatyczna instalacja =

1. Zaloguj się do panelu administracyjnego WordPress
2. Przejdź do **Wtyczki** > **Dodaj nową**
3. Wyszukaj "Deweloper Jawne Ceny"
4. Kliknij **Zainstaluj** i następnie **Aktywuj**

= Ręczna instalacja =

1. Pobierz plik ZIP wtyczki
2. Przejdź do **Wtyczki** > **Dodaj nową** > **Wgraj wtyczkę**
3. Wybierz pobrany plik ZIP i kliknij **Zainstaluj**
4. Po instalacji kliknij **Aktywuj wtyczkę**

= Po instalacji =

1. W menu administratora pojawi się nowy element **"Jawne Ceny"**
2. Kliknij na niego aby rozpocząć konfigurację
3. Wprowadź dane swojej firmy deweloperskiej
4. Dodaj pierwszą inwestycję i cenniki mieszkań
5. Wygeneruj pierwsze pliki danych

== Frequently Asked Questions ==

= Czy wtyczka jest zgodna z polskim prawem? =

Tak, wtyczka została stworzona zgodnie z wymogami Ustawy z dnia 21 maja 2025 r. o zmianie ustawy o ochronie praw nabywcy lokalu mieszkalnego. Generuje pliki w formatach wymaganych przez portal dane.gov.pl. Użytkownik ponosi odpowiedzialność za poprawność wprowadzanych danych.

= Czy mogę używać wtyczki dla wielu inwestycji? =

W ramach jednej inwestycji możesz dodawać nieograniczoną liczbę mieszkań i zarządzać cennikami dla każdego lokalu osobno.

= Czy pliki są automatycznie udostępniane publicznie? =

Tak, po wygenerowaniu plików są one automatycznie dostępne pod publicznymi adresami URL, które możesz przekazać organom państwowym.

= Czy wtyczka wspiera automatyczne aktualizacje danych? =

Wersja darmowa wymaga ręcznego generowania plików poprzez kliknięcie przycisku "Generuj manualnie" w panelu administracyjnym. 

Funkcje automatycznego publikowania danych (zaplanowane generowanie plików, automatyczne aktualizacje) są dostępne w wersji premium - więcej informacji na https://www.deweloperjawneceny.pl/?utm_source=wordpress&utm_medium=general-link&utm_campaign=promotion.

= Gdzie znajdę wygenerowane pliki? =

Pliki są dostępne w sekcji "Publikacja danych" w panelu administratora wtyczki, a także pod publicznymi adresami URL.

= Czy wtyczka działa z każdym motywem WordPress? =

Tak, wtyczka działa niezależnie od motywu. Cały interfejs znajduje się w panelu administratora WordPress.

= Czy mogę wyświetlać lokale na mojej stronie? =

Tak, wersja darmowa oferuje podstawowe możliwości wyświetlania lokali na stronie internetowej. Wersja premium dostarcza rozszerzoną listę opcji prezentacji oferty dla klientów.

= Kto ponosi odpowiedzialność za zgodność z prawem? =

Użytkownik ponosi pełną odpowiedzialność za poprawność wprowadzanych danych i zgodność z aktualnymi przepisami. Wtyczka dostarcza jedynie narzędzie do zarządzania danymi.
